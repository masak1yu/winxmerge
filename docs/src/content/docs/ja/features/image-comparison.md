WinXMerge は画像ファイルのピクセルレベル比較をサポートしています。

## 対応フォーマット

PNG, JPEG, GIF, BMP, WebP, TIFF, ICO

## 3パネルビュー

- **左パネル**: 元の画像
- **右パネル**: 変更後の画像
- **差分オーバーレイ**: 変更ピクセルを赤、許容範囲内のピクセルを黄、同一ピクセルをグレーで表示

## コントロール

### ズーム

**10%〜400%** の連続ズームスライダーと、ウィンドウサイズに合わせてスケーリングする **Fit** モード。

### ブレンドスライダー

ブレンドスライダー（0〜100%）で、変更ピクセルのハイライトを左右パネルに調整可能な透明度で直接オーバーレイ表示。変更箇所をコンテキスト内で確認しやすくなります。

### 差分パネルの切替

差分オーバーレイパネルの表示/非表示を切り替えて、個々の画像に集中できます。

### 許容値

許容値スライダー（0〜255）は、どこまでのピクセル差を一致扱いにするかを指定します。判定には、2つのピクセルの各チャンネル（アルファを含む）の差のうち最大のものを使います。0 では完全に一致するピクセルだけを一致とみなします。JPEG の再エンコードで生じる微小な色ズレを無視したいときは値を上げてください。再計算はスライダーをドラッグ中ではなく、離したタイミングで行われます。許容値はタブごとに保持され、セッションをまたいで保存されません。
