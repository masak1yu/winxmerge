WinXMerge は比較対象のパスとオプションを WinMerge 互換の `.WinMerge` プロジェクトファイルとして保存し、あとから開き直せます。WinXMerge は起動間でセッションを復元しないため、保存した比較を再現する唯一の手段です。

## 開く・保存する

- **File → Open Project...** で `.WinMerge` ファイルを開くと、含まれる `<paths>` エントリごとに1つずつタブが開き比較が始まる
- **File → Save Project...** は現在のタブのみを保存する。保存先はダイアログで指定
- コマンドラインからも開ける: `winxmerge project.WinMerge` — 位置引数がこれ1つだけのときに限る。`.WinMerge` 拡張子の判定は大文字小文字を区別しない

## 読み書きする要素

| 要素 | 意味 |
| --- | --- |
| `left` / `right` | 比較対象の2パス |
| `middle` | 3-way 比較のベースファイル |
| `white-spaces` | 0=すべて比較 / 1=空白の変更を無視 / 2=空白をすべて無視 |
| `ignore-case`、`ignore-blank-lines`、`ignore-carriage-return-diff` | テキスト比較のトグル |
| `subfolders` | フォルダ比較でサブフォルダを再帰的に辿るかどうか |
| `compare-method` | フォルダ比較方式。0〜6（Full/Quick/Binary/Date/SizeDate/Size/Existence）。WinMerge の 7=Image に相当する機能は winxmerge になく、無視される |

winxmerge に対応する機能がない要素 — `filter`、`*-desc`、`*-readonly`、`window-type`、`table-*`、`unpacker`/`prediffer`、その他の `ignore-*`、`hidden-items`、および未知の要素全般 — は読み飛ばすだけで、開く処理が失敗することはない。

## 挙動

- ファイルに要素がないオプションは、WinMerge と同様に現在の設定を上書きしない。範囲外の値も同様に無視される。
- `subfolders` / `compare-method` はアプリ全体のフォルダ比較設定を変更する（コマンドラインの `/m` と同じ扱い）。そのため他のタブでのその後のフォルダ比較にも影響し、終了時にはその設定が保存される。テキスト比較のオプションは開いたタブにのみ適用される。
- `subfolders=0` は探索の深さを最上位のみに制限する。`subfolders=1` は無制限の深さに戻すが、それは深さが最上位のみに制限されていた場合に限る（すでにより深いカスタム設定がある場合はそのまま維持される）。保存時はこの逆の対応で書き出す。
- 相対パスはプロジェクトファイル自身のフォルダを基準に解決する。WinMerge と異なり、環境変数の展開は行わない。保存時のパスは常に絶対パスになる。
- `<paths>` エントリが複数あれば、その数だけタブが開く。左右いずれかのパスがないエントリや、3-way で3パスのいずれかがフォルダであるエントリ（3-way のフォルダ比較は未対応）はスキップされ、開いた数とスキップした数がステータスバーに表示される。
- XML として解析できないプロジェクトファイルは、開く代わりにステータスバーにエラーを表示する。
