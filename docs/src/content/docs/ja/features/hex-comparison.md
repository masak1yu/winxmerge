WinXMerge は、テキストとして差分表示できないファイルを読み取り専用の Hex/ASCII ビューで表示します。

## 使われるタイミング

先頭 8KB に NUL バイトを含むファイルはバイナリと判定され、自動的に Hex ビューで開かれます。以下の方法で明示的に Hex ビューへ切り替えることもできます。

- **File > Recompare As > Hex** — 現在のタブのファイルペアを Hex ビューに切り替え（**Normal** で元に戻せます）
- フォルダ比較のアイテムのコンテキストメニューにある **Compare as Hex**
- コマンドラインオプション `/t Binary`

## レイアウト

各行は16バイトを表示します。8桁のオフセット、左ファイルの16進バイトと ASCII 表示、続いて右ファイルの16進バイトと ASCII 表示という並びです。印字不能なバイトは ASCII 列に `.` と表示されます。

## 差分

バイトは同じオフセット同士で比較されます。挿入・削除されたバイトに対する再整列は行われないため、1バイトの挿入があるとそれ以降の全バイトが差分として表示されます。一方のファイルがそこで終端した場合、もう一方の残りのバイトはすべて差分として扱われます。差分のあるバイトはハイライト表示され、差分ナビゲーションで差分ブロック間を移動できます。現在の行もハイライトされます。

## 制限事項

- 再整列は行われません。テキスト差分エンジンと異なり、挿入・削除があるとそれ以降のバイトがずれたまま比較されます
- Hex ビューでは外部でのファイル変更は自動検出されません。再読み込みするには Rescan (F5) を使用してください
- View > Zoom は適用されません。Hex ビューにズーム機能はありません
- Hex ビューを選んだ状態はセッションをまたいで保存されません。次回開いたときは通常の自動判定に戻ります
- 既に起動しているインスタンスにファイルパスを転送する場合（`git difftool` 経由など）、`/t` は転送されずファイルパスのみが渡されます
- 読み取り専用です。Hex ビューからの編集・保存・コピー・エクスポート・印刷はできません
